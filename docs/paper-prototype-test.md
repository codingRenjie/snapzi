# 纸原型测试方案：H1 + H2

> 版本：v1.0 ｜ 日期：2026-09-30 ｜ 预计执行：一个周末 + 第三天（共 3 天，每天 ≤ 20 分钟）
> 对应文档：product-concept.md v0.2 第 7 章

---

## 0. 本测试验证什么

| 假设 | 内容 | 通过标准 |
|---|---|---|
| **H1** | 孩子买账：愿意玩「拍 → 认 → 拆」全流程，且能理解语素拆解 | ① 无家长催促下主动完成流程 ≥ 2 次（3 天内）；② 语素拆解题 5 题答对 ≥ 3 题 |
| **H2** | 产品有效果：通过照片贴纸学的字，脱离语境后仍记得 | 第三天用**换字体的裸字卡**测试前两天学的 8–10 个字，认出 ≥ 60% |

**不在本次测试范围**：H3（家长仪式可持续性，本次顺带观察）、H4（识别技术鲁棒性，另行技术 spike）、H5（长期习惯，等 MVP）。

**提前声明的纪律**：测试结果只有「通过 / 不通过」，没有「感觉还行」。记录表当场填，不凭记忆补。

## 1. 道具清单（全部用家里现成的东西）

| 道具 | 做法 |
|---|---|
| 拍照工具 | 爸爸或妈妈的手机 |
| 图卡贴纸 × 6 | A4 纸裁成 6 张。每张照片拍完后**当场**把手机里的照片给孩子看，家长在卡片上半部分画一个简单图形（或打印照片剪贴），下半部分手写汉字词（如「洗衣机」），字号要大 |
| 语素解释卡 | 不用做卡，家长口播：「洗衣机，洗衣服用的机器」 |
| 拆解练习卡 × 5 题 | 手问题卡，见 3.2 |
| 句框卡 × 2 | 「我家有 ___」「___ 很好玩」各一张，词卡可嵌入 |
| 裸字卡 × 10 | 第三天用。**关键道具**：每个字打印三种字体（黑体、楷体、圆体），纯白底，无任何图案——这是去语境化检验的核心 |
| 相册墙 | 冰箱门或一面墙 + 胶带，贴纸学完就贴上去 |
| 观察记录表 | 第 5 章，打印 3 份（每天一张） |

## 2. 选词设计（有讲究的，不要临时换）

第一天拍：**洗衣机、电视机、冰箱**；第二天拍：**饮水机、微波炉、衣柜**（或孩子自己提议的，同类家电优先）。

理由：

- 全部为口语熟悉词（音-义锚点已有，只欠字形）——模拟产品主线
- 暗藏两个语素家族：「机」出现 3 次（洗衣机 / 电视机 / 饮水机），「电」出现 2 次（电视机 / 电冰箱说法）——第三天可以观察孩子是否**自发发现**「它们都有机字」（产品里的「织网」时刻，顺带验证）
- 复杂度分层：「衣、电、水」简单可考；「视、微、箱」复杂——正好测试双坐标分层的必要性（复杂字孩子记不住的预期本身就是数据）

目标字（进入考核的）：**衣、机、电、视、冰、箱、水、炉** 共 8 个（第二天结束后再补 2 个简单字到 10 个，视孩子状态）。

## 3. 三天流程编排

### Day 1（约 20 分钟）

**① 点火（亲子，约 5 分钟）**
爸爸带孩子在家里走：「宝宝，我们要不要学习洗衣机？」孩子同意 → 拍照 → 当场制作贴纸（画/贴图 + 手写词），爸爸口播语素解释。重复 3 次。

> 观察点：孩子对「拍哪个」有没有自己的主张？讨论环节他参与还是敷衍？

**② 孩子独立玩（约 10 分钟，家长退出到一旁只观察）**

- **认**：孩子自己翻 3 张贴纸，每张跟读一遍（语音提示由家长扮演：「点一下，听听它怎么说」）
- **拆**（灵魂环节，口答 5 题）：
  1. 「洗衣服用的机器，是哪一张？」（指认）
  2. 「电视机和电冰箱，有没有一样的字？」（语素觉察）
  3. 「如果有一种机器，是用来喝水的，它可能叫什么？」（饮水机未学时问，测语素迁移；已学则换「吹头发的机器」）
  4. 「『衣』这个字，除了洗衣机，还在哪一张里藏着？」（衣柜为干扰项——未出现，看孩子如何应对）
  5. 「用『机』字你能说出几个东西？」（开放题）
- **说**：句框卡填词——「我家有 ___」，孩子把词卡嵌进去读出来

> 观察点：家长离场后孩子能否继续？拆解题卡壳时的反应（放弃 / 猜 / 求助）？

**③ 收（1 分钟）**
孩子自己把 3 张贴纸贴上相册墙，击掌结束。**不做任何考核**。

### Day 2（约 20 分钟）

同 Day 1 结构，拍饮水机 / 微波炉 / 衣柜。两处变化：

- 开场前不做任何提醒，**观察孩子是否主动提起**「我们拍照学字吧」——这是 H1 第 ① 条标准的关键数据
- 「拆」环节混入 2 题 Day 1 的字（自然复习，不告诉孩子）

### Day 3（约 15 分钟，无新照片）

**去语境化测验**（包装成游戏：「今天我们玩字体侦探」）：

- 逐一出示 10 张裸字卡（字体随机：黑体 / 楷体 / 圆体），问「这是什么字？」
- 认得出 → 记 1 分；认不出 → 提示「它住在你拍的哪张照片里？」，能回忆起来记 0.5 分（语境依赖的证据，单独标注）
- 结束后再做一次「贴纸配对」：裸字卡贴回对应照片贴纸——测「有语境能认、无语境不认」的具体是哪些字

> 观察点：哪些字去语境化后丢失？丢失的字有什么共性（复杂？没进过拆解练习？第二天学的？）

## 4. 测试纪律（给执行的家长）

1. **你是观察员，不是老师**：不教、不提示答案、不纠正（发音除外）。孩子卡住时，沉默 10 秒，记录反应，再进入下一题
2. **不告诉孩子这是测试**，裸字测验必须包装成游戏
3. 每天同一时段、每次 ≤ 20 分钟，孩子明显烦躁就中止，记录中止点——**烦躁本身就是数据**
4. 记录表当场填，凭记忆补的记录无效
5. 妈妈在旁边时忍住「哎呀这个昨天刚学过」——我们正是要测量「昨天学过今天还剩多少」

## 6. 结果解读分支

| 结果 | 含义 | 下一步 |
|---|---|---|
| H1 ✓ H2 ✓ | 主线成立 | 进入 MVP 规划；H4 技术 spike 启动 |
| H1 ✓ H2 ✗ | 孩子爱玩但记不住——巩固环节太弱 | 调整设计：减少每课新字量、加密复习间隔，一周后复测 H2 |
| H1 ✗ H2 ✓ | 能记住但没兴趣——入口形态有问题 | 拆解到底是哪一环无趣（拍？贴纸？拆题？），逐项替换重测 |
| H1 ✗ H2 ✗ | 主线存疑 | 回到讨论，不投入开发 |
| 拆解题大面积失败 | 灵魂环节超龄 | 语素拆解降级为纯口播故事（不提问），半年后再引入练习 |

**无论结果如何，把三张记录表和结论归档到 research/ 目录**——这是产品的第一份实证数据。
