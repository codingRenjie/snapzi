# 拍个字（SnapZi）MVP 功能清单

版本：v1.0 ｜ 日期：2026-10-05 ｜ Bundle ID：`com.renjie.snapzi`  
依据：[SnapZi-PRD.md](../SnapZi-PRD.md)、[keyword-families.md](./keyword-families.md)

---

## 1. MVP 要证明什么

在 App Store / TestFlight 可安装的 iPad 应用里，跑通 **一条完整日课**，并验证 PRD 已确认的方向在真机上仍成立：

1. 家长 **30 秒内选字**，孩子 **约 10–15 分钟** 完成一次会话（不要求家长全程陪同）。
2. **实拍照片** 是默认路径，学习内容与「我们拍的」强绑定。
3. 至少一种 **游戏 = 认知练习**（非无关娱乐）。
4. 掌握度与复习 **有记录、能延续到第二天**（算法可先简化）。

**不在 MVP 内证明：** 完整字表规模、书写笔顺、网络图库、云端账号、绘本/AI 句子。

---

## 2. 版本划分

| 里程碑 | 目标 | 建议周期（单人业余） |
|--------|------|----------------------|
| **MVP 0.1（内部）** | 真机可演示：选字 → 拍 2–3 张 → 认读 → 一个小游戏 → 本地保存 | 3–5 周 |
| **MVP 1.0（TestFlight）** | 完整日课骨架 + 简化复习 + 家长小结 + 隐私与审核材料齐 | +3–5 周 |

以下 Must / Should / Won’t 以 **MVP 1.0** 为交付线；**MVP 0.1** 只做 Must 中带「0.1」标记的项。

## 3. Must — 首发必做

### 3.1 平台与基础

| 项 | 说明 | 0.1 |
|----|------|-----|
| iPad 优先 UI | 横屏为主；大触控目标（快门、选项）；适配 iPad mini 与 11/13 寸 | ✓ |
| 仅 iPad 或 iPhone 兼容 | 建议 **iPad Only**（`TARGETED_DEVICE_FAMILY = 2`），减少首版适配面 | ✓ |
| 本地数据 | 字、照片路径、掌握度、复习日期存设备本地（SwiftData / Core Data） | ✓ |
| 无账号、无后端 | 不上传用户内容；App Store 隐私问卷与 [privacy-policy.md](./privacy-policy.md) 一致 | ✓ |
| 系统读音 | 关键字与关联词使用 **系统 TTS（AVSpeechSynthesizer）** 播放普通话 | ✓ |

### 3.2 内容与字表（首版 subset）

| 项 | 说明 | 0.1 |
|----|------|-----|
| 内置推荐字 | 从 [keyword-families.md](./keyword-families.md) 选 **12–20 个**关键字（建议首批：`门、车、灯、杯、书、水、园、球、店、果、鱼、包`） | ✓ |
| 关联词文案 | 每字 3–5 个关联词（静态 JSON/ plist），供选字页与拍摄任务展示 | ✓ |
| 暂不内置全表 | 其余关键字 **v1.1+** 再扩 | — |

### 3.3 家长：选字（PRD §5.1）

| 项 | 说明 | 0.1 |
|----|------|-----|
| 选字入口 | 独立 **家长区**（简单 PIN 或「长按设置 2 秒」进入，防儿童误触） |  |
| 推荐候选 | 展示 3–5 个推荐字 + 各字可拍关联词提示 | ✓ |
| 掌握概览 | 每字显示：未学 / 学习中 / 已稳固（MVP 可合并为 3 档标签） |  |
| 选定本次关键字 | 一次会话只学 **1 个新关键字** | ✓ |

### 3.4 拍照（PRD §6）

| 项 | 说明 | 0.1 |
|----|------|-----|
| 相机权限与说明 | Info.plist 用途文案；首次引导一句话 | ✓ |
| 简化拍摄 UI | 大快门、少设置；**0.1 可手动快门**，稳定后自动拍为 1.0 增强 | ✓ |
| 拍摄任务 | 按关联词引导拍 **2–3 张**（如「门」：大门、柜门… 家长可跳过某一张） | ✓ |
| 确认环节 | 拍完后「这是我们拍的什么呀？」选/确认对应词语 | ✓ |
| 照片标记 | 列表与学习中标注 **「我们拍的」**（MVP 无网络图，暂不展示「图库图」） | ✓ |
| 存储 | 照片存 App 沙盒；卸载即删 | ✓ |

### 3.5 日课会话（PRD §4.2，MVP 可略缩时长）

| 环节 | MVP 1.0 范围 | 0.1 |
|------|----------------|-----|
| 1. 热身复习 | 若有「到期」旧字则 1 个；形式：**照片快闪认字** 或 **听音选字** 二选一 |  |
| 2. 新字引入 | 展示本次字族照片 + 词 + 读音；关键字高亮 | ✓ |
| 3. 巩固游戏 | **至少 1 种**：听音选字 / 看图选字 / 看字选图（建议先做 **看图选字**） | ✓ |
| 4. 书写 | **不做**（Won’t）；收尾文案提示「正式写字请用纸笔」 | — |
| 5. 收尾 | 「你已认识 N 个字」+ 可选 **现实任务** 文案（「路上找找『门』」） | ✓ |

### 3.6 掌握度与复习（PRD §4.1、§4.6 简化版）

| 项 | 说明 | 0.1 |
|----|------|-----|
| 状态（MVP） | **三档即可**：初识 → 认读 → 稳固（辨认并入认读→稳固的升级条件） |  |
| 升级规则 | 完成引入 + 游戏无严重错误 → 认读；复习答对 1 次 → 稳固（细则实现时可调） |  |
| 复习间隔 | 简化 Leitner：**1 → 3 → 7 天** 三档；答错回到 1 天 |  |
| 每日到期 | 启动日课时计算「今日到期」字，供热身使用 |  |
| 现实复现 | **仅文案任务 + 家长手动标记「找到了」**（可选加 1 档间隔奖励） |  |

### 3.7 合规与上架材料

| 项 | 说明 |
|----|------|
| 隐私政策 URL | 部署 [privacy-policy.md](./privacy-policy.md) 至可公开 HTTPS（GitHub Pages / 个人站点） |
| App 隐私标签 | 声明相机、本地存储；**不**声明追踪、第三方广告 |
| 年龄分级 | 按问卷如实选；儿童向内容避免外链与社交 |
| 审核备注 | 说明：家长选字、亲子拍照、数据不出设备、非 unattended 儿童产品 |

## 4. Should — 1.0 强烈建议（可延到 1.0.1）

| 项 | 说明 |
|----|------|
| 取景辅助 | 中央目标框 + 主体稳定后自动快门（Vision / 简易稳定性检测） |
| 第二种巩固游戏 | 如听音选字，与第一种错开练维度 |
| 迷你图文句 | 1 图 + 1–2 句模板句，孩子指认句中字（PRD §4.7） |
| 家长异步小结 | 会话结束后卡片：今日字、照片缩略图、建议现实任务 |
| 从相册补拍 | 仅「我们拍的」路径：允许从相册选图补一张（仍算实拍类） |
| 无障碍基础 | 动态字体部分支持；VoiceOver 对主按钮有 label |
| 崩溃与基础指标 | Apple 自带崩溃报告；可选匿名「会话完成率」本地汇总（仍无上传） |

---

## 5. Won’t — 明确不做（MVP）

| 项 | 原因 |
|----|------|
| 用户注册 / 登录 / 云同步 | 隐私与开发量；后续 v2 再议 |
| 网络搜索导入图片 | PRD 兜底路径；首版强化实拍 |
| 描红、笔顺、PencilKit | PRD 5–6 岁书写；独立里程碑 |
| 完整掌握度五态 + SM-2 | 先用三档 + 三间隔 |
| 全量 keyword-families 字表 | 内容运营与测试成本 |
| AI 生成句子 / 绘本 | PRD 待决策 |
| 内购、广告、第三方统计 SDK | 儿童与审核风险 |
| iPhone 专用布局优化 | 资源聚焦 iPad |
| 多孩/profile | 单设备单档案即可 |

## 6. MVP 0.1 验收标准（内部演示）

- [ ] 家长在家长区选「门」，完成 2 张拍摄与确认  
- [ ] 孩子完成引入 + 1 个小游戏，听到系统读音  
- [ ] 杀进程重启后，照片与学习记录仍在  
- [ ] iPad mini 与一台大屏 iPad 均可完成全流程，无挡按钮  
- [ ] 15 分钟内可收束（0.1 可无复习环节）

---

## 7. MVP 1.0 TestFlight 验收标准

- [ ] 连续 **3 天** 日课：Day1 新字、Day2 新字 + 旧字热身、Day3 复习间隔生效  
- [ ] 至少 **2 个家庭** 各完成 ≥3 次会话（你 + 1 户外家庭）  
- [ ] 隐私政策 URL 可打开；Connect 隐私标签与 App 行为一致  
- [ ] 无 P0 崩溃；相机拒绝权限时有友好说明与返回路径  

---

## 8. 建议技术栈（实现参考，非强制）

- **UI：** SwiftUI  
- **数据：** SwiftData（iOS 17+）或 Core Data；最低系统建议 **iPadOS 17+** 以减样板代码  
- **相机：** AVFoundation  
- **音频：** AVSpeechSynthesizer（中文 `zh-CN`）  
- **工程：** Xcode 单 target，Bundle ID `com.renjie.snapzi`
