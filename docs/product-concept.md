> 产品名：拍个字 ｜ 英文开发代号：SnapZi（bundle: com.snapzi.app）
> 版本：v0.2 ｜ 日期：2026-09-30 ｜ 状态：概念阶段

## 1. 一句话定位

**孩子拍下的生活，就是他的识字课本；爸爸妈妈陪他按下快门，算法负责让他记住。**

差异化叙事：洪恩、悟空们把产品定位为「学习 + 陪伴」，潜台词是家长装了就可以撒手——我们反对这个前提。「拍个字」不做能识字的电子玩具，做的是**亲子共学的工具**：家长参与点火，孩子独立练习，算法默默兜底。名字本身就是点火仪式的用语——「宝宝，我们拍个字吧？」

---

## 2. 背景与问题

### 2.1 真实场景

发起人家里有一个 5 岁的儿子，2027 年 9 月上小学，需要在约 12 个月内逐步建立识字量。现状：妈妈用识字卡片教，效果不好，且妈妈容易着急上火。

### 2.2 痛点拆解

| 痛点 | 本质 |
|---|---|
| 孩子缺动力 | 卡片是静态的、单向的、脱离生活语境 |
| 家长缺工具 | 不知道孩子哪些字会了哪些不会，只能凭感觉重复考 |
| 亲子关系在消耗 | 「教」变成了「监督」，学习场景伴随负面情绪 |
| 竞品的方向错误 | 洪恩/悟空用丰富动画和游戏让孩子「自己玩」，实质是电子保姆；富媒体刺激喧宾夺主（悟空每 1–2 次点击触发 10 多秒动画） |

### 2.3 北极星指标

不是「认识 800 个字」，而是：**入学前能自主阅读简单绘本。**

## 3. 产品理念（三条不可妥协）

### 3.1 贴近生活

不做从「一二三人口天」开始的 alphabet 式课程——那是红海，且无法避开现有产品的重资产竞争（动画、IP、课程体系）。5 岁孩子的口语里已有大量「音-义」绑定（会说「公交车」不认识这三个字），识字只是**给老朋友拍照片**——把「形」挂到已有的「音-义」锚点上。孩子的学习材料应该来自他自己的生活：他的 PS5、他的冰箱、他楼下的公交站牌。

### 3.2 扎实练习，没有废话

欣赏多邻国的原因不是游戏化，而是**每天 15 分钟扎实的练习**。对 5 岁孩子同理：每 8–10 分钟的学习单元里，一切动画和交互必须服务于「音-形-义」绑定，装饰性刺激（与字无关的变身动画、剧情过场）一律砍除。检验标准：**这个元素去掉后，孩子对字的理解会不会受损？不会受损的，就是该砍的。**

### 3.3 家长不撒手，但也不做监工

孩子成长中家长不能缺席——但家长的角色必须被严格设计，否则「参与」会退化回「人肉考字、着急上火」的老路：

- **家长是点火的人**：每天亲子一起讨论「今天学哪三个字」、一起拍下 3 张照片。这个仪式本身就是语素意识和印刷品注意力的训练（共读时指向文字的干预方式有实证支持）
- **家长是玩伴**：巩固复习设计为亲子可以一起玩的游戏；家长有时间就参与，没时间孩子自己也能玩
- **家长不是考官**：哪些字会了哪些不会，看报告，不人肉考
- **允许缺席，降级运行**：家长忙的时候，孩子用存量照片和图鉴自主复习，产品依然完整可用。家长参与是增强件，不是硬门槛——否则「不撒手」会变成「被绑架」

商业说明：发起人明确「商业变现先不考虑，优先做正确的事」。记录一个判断供日后参考：「拒绝电子保姆」本身可能就是打动付费家长的最佳差异化叙事——竞品最大的槽点正是「孩子只玩游戏不学字」。

## 4. 认知科学地基（已验证，不再讨论，只引用）

详细文献见 [research/](/Users/renjie/Workspace/Easy_Read/research/) 目录下的检索结果。

### 4.1 一个字的微观四步

1. **初识**：整体视觉记忆，把「形」挂到已有的「音-义」锚点上（paired-associate learning）。5 岁孩子把字当「小图画」整体记住，记忆钩子的质量决定初识质量
2. **巩固**：间隔重复对抗遗忘。纯机械过程，完全交给算法，不占孩子心智、不占家长情绪
3. **激活**：在词语、句子、真实场景中用起来。成就感（我能自己读了）是最强内在动机
4. **织网**：部件规律自发涌现（正字法意识）。规律是被「发现」的，不是被「讲授」的；我们能做的是储备原材料、制造发现瞬间

### 4.2 关键证据与警戒线

- **因果方向随阶段反转**：幼儿园阶段是「认字量 → 催生规则意识」（单向），一年级双向，二三年级反转。学前期的工作就是储备原材料，不要教规则
- **5 岁正字法意识刚萌芽**：能识别部件形态错误（87% 准确率），但部件位置意识刚超随机水平；学前识字量与规则意识无显著相关
- **⚠️ 语境依赖是本产品最大的理论风险**：环境文字研究经典结论——能认出麦当劳标志的孩子，字抽离语境就不认识了（Masonheimer et al., 1984，454 次引用）；汉语学前儿童实验结论一致（Zhao et al., 2014, PLoS ONE）。**对策：每个字必须通过「去语境化检验」才算学会**（见 6.1）
- **视觉复杂度是硬约束**：初学儿童字形记忆容量远小于成人；笔画数/词长显著影响词汇学习效果。选字必须双坐标：口语熟悉度 × 学习成本（见 6.2）
- **语素意识是隐藏红利**：控制其他变量后，语素意识独立预测汉语阅读理解。识字过程天然训练「一个音节 = 一个字 = 一个意义单位」的觉察——「游戏机 → 洗衣机」式拆解是产品的灵魂环节

```

│  拍 【亲子共拍，点火仪式】                                  │
│  家长和孩子讨论「今天学哪三个字」，一起拍 3 张照片            │
│  （孩子也可自己拍；家长缺席时用存量照片降级运行）              │
└──────────────────────┬───────────────────────────────────┘
                       ▼
┌──────────────────────────────────────────────────────────┐
│  认 【孩子独立完成】                                       │
│  识别物体 → 生成图卡贴纸（照片 + 汉字词 + 读音）             │
│  点击贴纸听语素解释：「游戏机，玩游戏用的机器」               │
│  ※ 识别结果按双坐标自动分层（见 6.2），不是全部进教学        │
└──────────────────────┬───────────────────────────────────┘
                       ▼
┌──────────────────────────────────────────────────────────┐
│  拆 【灵魂环节，孩子独立完成】                              │
│  语素拆解小练习：「用来洗衣服的是？——洗衣机」                 │
│  组装式表达（不是造句）：给句框填词「我有___」「___很好玩」   │
└──────────────────────┬───────────────────────────────────┘
                       ▼
┌──────────────────────────────────────────────────────────┐
│  收 【激励，积累可视化】                                    │
│  贴纸进入「我的生活相册」，点亮的字进入图鉴                  │
└──────────────────────┬───────────────────────────────────┘
                       ▼

│  复习 【隐形引擎：算法排期 + 去语境化检验】                  │
│  间隔重复算法从相册里挑到期的贴纸，但考题是换字体、           │
│  换背景、裸字形态——认得出才算数（见 6.1）                   │
│  亲子模式：家长可挑选图卡和孩子玩复习游戏（增强件）           │
└──────────────────────┬───────────────────────────────────┘
                       ▼
┌──────────────────────────────────────────────────────────┐
│  织网 【规律被孩子自己发现】                                │
│  同一语素的字积累到 3 个（游戏机/洗衣机/手机），              │
```

**角色分工一览**：家长负责点火（拍）和陪伴（复习游戏）；孩子负责学（认、拆）和探索（拍）；算法负责记忆（复习排期）和质检（去语境化检验）。

## 6. 关键设计决策

### 6.1 去语境化检验（产品生死线）

孩子认得出「这张照片里的游戏机」不等于认得出「绘本里的游戏机」。每个字的学习状态机里，「学会」的判定必须包含：**脱离原照片语境**（不同字体、纯色背景、裸字）后仍能识别。这是本产品区别于「高级识物卡」的生死线，也是家长端报告里「真正认识 N 个字」这个数字可信的前提。

### 6.2 双坐标分层：识别结果不全部进教学

每个识别出的词按两个坐标分层处理：

| | 字形简单（学习成本低） | 字形复杂（学习成本高） |
|---|---|---|
| **口语熟悉** | 正课：教 + 练 + 考（如「车」「门」「电」） | 词卡整体认读：只认不考不拆（如「电饭煲」「变形金刚」） |
| **口语陌生** | 后置：暂不进教学 | 忽略 |

- 复杂词的处理三件套：**整体词卡**（sight word 式，混脸熟）+ **语素故事**（「电饭煲 = 用电的 + 煮饭的 + 锅」，三个语素各配画面）+ **延迟拆解**（等「火」「保」等部件入库后再回来学）
- 5 岁男孩大概率天天拍 PS5 和奥特曼——**重复拍摄不是 bug 是 feature**：第 5 次拍游戏机就是一次天然间隔重复，产品应该欢迎而不是提示「拍过了」

### 6.3 注意力预算

承袭 v0.1 的原则并保留：每个交互元素必须服务于「音-形-义」绑定；练习即游戏而非对练习的补偿；每单元新字 2–3 个（约 3 分钟），其余时间给复习和应用——识字的瓶颈在巩固而非输入。

### 6.4 家长端

- **报告**：今天学了什么、哪些字不牢、记忆曲线——消灭人肉考字
- **亲子复习游戏**：家长从相册挑图卡和孩子玩的对战/合作小游戏（家长有时间时的增强件）
- **不设计的东西**：不给家长布置任务、不做打卡催签、不推送焦虑

## 7. MVP 范围

**验证的核心假设**：5 岁孩子能否在「家长点火 3 分钟 + 自己玩 10 分钟」的结构下，持续两周以上主动完成拍照识字，且**去语境化**后的记住率可测。

| 做 | 不做（第一版） |
|---|---|
| 拍照 → 图像识别 → 图卡贴纸（图 + 词 + 音） | 视频/动画内容 |
| 语素解释语音（模板化生成） | 语素家族网络（先手工配置高频 20 个语素） |
| 1–2 种拆解小练习 + 组装式句框 | 笔顺描红 |
| 简化间隔重复（错的明天重现 + 三天后重现） | 完整 SM-2 |
| 去语境化检验（换字体/裸字认读）——**必须在 MVP 里，它是假设的一部分** | 亲子复习游戏 |
| 我的生活相册 + 字图鉴 | 建设型世界 |
| 家长端极简报告 | 周报、时长控制、课程配置 |
| 降级运行：无新照片时用相册复习 | 拍照引导/推荐拍摄目标 |

技术风险前置验证：儿童拍摄照片（模糊、角度怪、光线差）下的物体识别鲁棒性——这是 MVP 前就该做的技术 spike。

## 8. 差异化与护城河

| 维度 | 洪恩/悟空/叫叫 | 拍个字 |
|---|---|---|
| 内容来源 | 统一课程推送给所有孩子 | 每个孩子自己的生活照片 |
| 家长角色 | 撒手（实际）/ 焦虑（结果） | 点火 3 分钟 + 看报告，亲子复习游戏可选 |
| 语境 | 屏幕内虚构场景 | 孩子的真实世界 |
| 复习 | 固定节奏推送 | 每字独立间隔重复 + 用孩子自己拍的照片复习 |
| 质检 | 无（跟读不校验、语境不剥离） | 去语境化检验通过才算学会 |

**护城河（现在就开始积累）**：

1. **语素图谱**：以「机、车、水、电」等高频语素为节点的汉字家族网络——内容资产，抄不走
2. **个人语料库**：孩子拍过什么、生活里高频词是什么、哪些字到期——数据飞轮随使用时长加深
3. **价值观叙事**：「拒绝电子保姆」的品牌立场本身

### 10.2 「公开发行」的硬性要求（保留）

1. 合规先行：儿童隐私保护（《儿童个人信息网络保护规定》）、苹果 Kids Category 规则（无行为广告、购买藏家长门槛后）、国内渠道需软著 + 备案
2. MVP 完成度上移：家长门槛、隐私政策、时长控制、崩溃监控必须内置
3. 儿子是首席测试官但不是唯一验收标准：需 3–5 个家庭小范围试用
4. **v0.2 新增注意**：拍照功能涉及儿童照片——这是最敏感的隐私数据类别，合规设计（本地优先、不上传原始照片或明确告知）必须在架构第一天就定下来
